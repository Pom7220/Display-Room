No Chrome install, no certificate install, no sign-in required.

2

Troubleshooting

SymptomCauseFix
Black screen after rebootWiFi not ready when APK launched (boot too fast)Wait 90s after power-on. If persists: open RIS Kiosk app manually to re-trigger
Display returns to Android home screenAPK not set as default launcher, or ForegroundWatchService stoppedOpen RIS Kiosk app → it will relaunch WebView. Reboot to restore auto-launch
Red error banner at top of screenJavaScript error in WebView (Chromium 30 compatibility)Check if latest index.html version is deployed. Remote reload from dashboard. Reboot if still showing.
"No meetings" or stale dataWiFi disconnected or Cloudflare Worker issueCheck WiFi. Open dashboard → check tablet heartbeat status. Reboot tablet.
Room shows "Available" but Outlook shows bookedCalendar refreshes every 2 minutesWait up to 2 min. If still wrong: check service account has Full Access to room mailbox in Exchange Admin
Card shows red after meeting endsAuto-release or End pressed — brief rendering delayFixed in v3.10.110 — re-renders immediately. If persists, remote reload from dashboard.
Room shows FREE but upcoming meetings visible in listExchange auto-accept delay for non-approval rooms (usually <10 sec)Fixed in v3.10.109 — tentative meetings treated as confirmed for non-approval rooms. Resolves automatically.
APK install: "conflicting signature"Different signing key from previous APK versionSettings → Apps → uninstall old RIS Kiosk → install new APK
Display shows wrong room nameRoom not selected in setup, or SharedPreferences corruptedOpen RIS Kiosk app → re-select room → Save
Tablet offline on dashboard for >30 minWiFi dropped, tablet frozen, or display crashedPhysical check required — verify tablet is powered and connected to WiFi. Reboot if needed.

Remote management (via dashboard)

Open dashboard → Admin panel → available actions:

ActionEffect
Reload AllSends reload command to all tablets — display refreshes within 2 minutes (next poll cycle)
Status viewShows last heartbeat time for each tablet — confirms online/offline without physical visit
ℹ Tablets poll for commands every 2 minutes. Remote reload is not instant — allow up to 2 minutes for the tablet to act.
