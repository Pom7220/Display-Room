Troubleshooting

SymptomCauseFix
Microsoft account picker appearsAzure AD session expired (after 24h)Sign in once. For permanent fix: IT sets Persistent browser session on service account (extends to 90 days)
"No meetings" or blank screenWiFi disconnected or token expiredCheck WiFi. Long-press gear (5 sec) for debug log. Reboot to trigger auto-launch
Room shows "Available" but Outlook shows bookedCalendar refreshes every 90 secWait 90 sec. If still wrong: check service account has Full Access to room mailbox in Exchange Admin
Old version still showingService worker cached old filesEnsure CACHE_VERSION in sw.js was bumped. Tablets auto-reload within 5 min of inactivity
APK install: "conflicting signature"Different signing key from old APKSettings → Apps → uninstall old APK → install new one
